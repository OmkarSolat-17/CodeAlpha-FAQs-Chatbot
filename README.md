# 🤖 FAQ Chatbot (Task 2)

An NLP-based FAQ chatbot developed using Python and Flask. The chatbot processes user queries and matches them with relevant predefined answers using text similarity techniques.

## ✨ Features

- Interactive chatbot interface
- NLP-based query processing
- Text similarity-based FAQ matching
- Automated response generation from predefined FAQs
- Dark-themed modern UI
- Structured FAQ database using JSON

## 🛠️ Tech Stack

- **Python** – Core programming
- **Flask** – Backend framework
- **Natural Language Processing (NLP)** – Query processing
- **Scikit-learn** – Text similarity techniques (if used in the final implementation)
- **JSON** – FAQ data storage
- **HTML5, CSS3, JavaScript** – Frontend

## ⚙️ Installation & Setup

### 1. Clone the repository

## 🧠 How It Works

1. The user enters a question in the chatbot interface.
2. The input is processed using NLP techniques.
3. The query is compared against stored FAQ questions.
4. The most relevant matching answer is returned.
5. The response is displayed in the chatbot interface.

## 🎯 Project Objective

To build an intelligent FAQ chatbot that demonstrates basic NLP, text similarity, and web application development.
